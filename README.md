# Coin Counting Game 🪙

A cheerful shop game that teaches K–3 kids to add coins and make spending decisions: drag realistically-sized U.S. coins onto the shop counter, tap a coin to flip it, and pay the exact price.

## Play

Open `index.html` in any modern browser — no build step, no dependencies.

## Deploy

This is a single static file, ready for Vercel's free tier: import this repo in Vercel and deploy. No build command needed.
